# 🛡️ Anti-Raid Discord Bot

Полнофункциональный бот для защиты Discord-сервера от рейдов, нюков, спама и подозрительной активности.

## ⚡ Возможности

### 🔥 Anti-Nuke (Защита от уничтожения)
- **Удаление каналов** — если пользователь удалил 2+ каналов → мгновенный бан
- **Удаление ролей** — если пользователь удалил 3+ ролей → бан
- **Массовый бан** — если кто-то банит 3+ людей за минуту → бан
- **Массовый кик** — если кто-то кикает 5+ людей за минуту → бан
- Автоматическое снятие опасных прав перед баном

### 🚨 Anti-Raid (Защита от рейдов)
- Обнаружение массового входа (5+ за 10 секунд)
- Автоматический рейд-режим с киком новых участников
- Анализ подозрительных аккаунтов (возраст < 7 дней)
- Карантинная роль для подозрительных пользователей
- Ручное управление рейд-режимом

### 🔇 Anti-Spam (Защита от спама)
- Лимит сообщений: 10 за 5 секунд → авто-мут
- Обнаружение дубликатов сообщений
- Защита от массовых упоминаний (@everyone, пинги)

### 📋 Логирование
- Автоматическое создание канала `#anti-raid-logs`
- Входы/выходы участников с анализом возраста аккаунта
- Создание/удаление каналов и ролей
- Предупреждения об опасных правах

## 🚀 Установка

### 1. Требования
- Python 3.10+
- Discord Bot Token

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка Discord Developer Portal
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
2. Создайте новое приложение → Bot
3. Включите **Privileged Gateway Intents**:
   - ✅ SERVER MEMBERS INTENT
   - ✅ MESSAGE CONTENT INTENT
4. Скопируйте токен бота

### 4. Настройка config.json
```json
{
    "token": "ВАШ_ТОКЕН_БОТА",
    "owner_ids": [123456789],
    "whitelist_ids": [123456789]
}
```

### 5. Запуск
```bash
python bot.py
```

### 6. Приглашение на сервер
Используйте OAuth2 URL с правами:
- `Administrator` (рекомендуется для полной защиты)
- Или минимально: `Ban Members`, `Kick Members`, `Manage Roles`, `Manage Channels`, `View Audit Log`, `Moderate Members`

**Важно:** Роль бота должна быть **выше** всех остальных ролей в настройках сервера!

## 📝 Команды

| Команда | Описание | Права |
|---------|----------|-------|
| `!antiraid status` | Статус всех модулей | Администратор |
| `!raidmode [on/off/status]` | Управление рейд-режимом | Администратор |
| `!whitelist add @user` | Добавить в белый список | Администратор |
| `!whitelist remove @user` | Убрать из белого списка | Администратор |
| `!whitelist list` | Показать белый список | Администратор |

## ⚙️ Настройка порогов

Все пороги настраиваются в `config.json`:

```json
{
    "anti_nuke": {
        "channel_delete_limit": 2,
        "channel_delete_window_seconds": 60
    },
    "anti_raid": {
        "join_limit": 5,
        "join_window_seconds": 10,
        "suspicious_account_age_days": 7
    },
    "anti_spam": {
        "message_limit": 10,
        "message_window_seconds": 5
    }
}
```

## 🔒 Белый список

Пользователи в `owner_ids` и `whitelist_ids` освобождены от всех проверок. Добавляйте туда только **абсолютно доверенных** администраторов.
